# 🧠 iVoc Local MCP Server

שרת **Model Context Protocol (MCP)** מקומי המאפשר לסוכני AI (כגון Antigravity, Claude, Cursor) להתחבר לאפליקציית **iVoc**, לתרגל אוצר מילים לפסיכומטרי/אמירם, לנהל אלגוריתם חזרות מרווחות (Leitner Spaced Repetition), לתשאל את מילון 3,705 המילים, ולעקוב אחר סטטיסטיקת הלמידה.

---

## 🛠️ כלים זמינים (MCP Tools)

| כלי | תיאור | פרמטרים |
|---|---|---|
| `ivoc_get_next_question` | שולף את שאלת התרגול הבאה על פי תור החזרות המרווחות (Leitner). מחזיר מילה, אות, תיבה נוכחית (0–4) ו-4 אפשרויות בחירה (1 נכונה + 3 מסיחים). | `letter` (אופציונלי: 'A'–'Z' או 'ALL'), `showHebrewFirst` (boolean) |
| `ivoc_submit_answer` | שולח את התשובה שנבחרה. מקדם את המילה בתיבות לייטנר (0 ➜ 1 ➜ 2 ➜ 3 ➜ 4 ➜ 5) במענה נכון, או מחזיר לתיבה 0 לחזרה מוקדמת במענה שגוי. | `wordId` (string, חובה), `selectedAnswer` (string, חובה) |
| `ivoc_get_stats` | מחזיר נתונים סטטיסטיים מפורטים: התפלגות לפי תיבות לייטנר, אחוז דיוק, כמות ניסיונות, מילים שנלמדו. | אין |
| `ivoc_lookup_word` | חיפוש מהיר במאגר 3,705 המילים לפי מילה באנגלית או תרגום בעברית. | `query` (string, חובה), `limit` (int, ברירת מחדל 10) |
| `ivoc_reset_progress` | איפוס התקדמות הלמידה (תיבות, מונה חזרות, דיוק) עבור אות מסוימת או עבור כל המילון. | `letter` (אופציונלי: 'A'–'Z' או 'ALL') |

## ⚙️ הגדרת השרת בלקוחות MCP

### Antigravity / Claude Desktop / VS Code
הוסף את ההגדרה לקובץ `mcp_config.json`:

```json
{
  "mcpServers": {
    "ivoc": {
      "command": "python",
      "args": [
        "mcp/server.py"
      ],
      "env": {
        "PYTHONIOENCODING": "utf-8"
      }
    }
  }
}
```

## 🎮 הרצה אוטונומית (Play by Yourself)

כדי להריץ סימולציה שבה שחקן AI מתחבר דרך פרוטוקול ה-MCP, פותר שאלות, מדגים מענה נכון ושגוי, ומציג את התקדמות התיבות של לייטנר:

```bash
# הרצת 15 שאלות לדוגמה
python mcp/play_ivoc.py 15

# הרצת 30 שאלות
python mcp/play_ivoc.py 30
```

## 📐 אלגוריתם Leitner מיושם

- **תיבה 0**: מילים שטרם נלמדו או מילים שטעו בהן.
- **תיבה 1**: חזרה לאחר 2 שאלות.
- **תיבה 2**: חזרה לאחר 5 שאלות.
- **תיבה 3**: חזרה לאחר 12 שאלות.
- **תיבה 4**: חזרה לאחר 28 שאלות.
- **תיבה 5**: נלמד בהצלחה (Mastered) — המילה הושלמה ויוצאת מסבב השאלות הפעיל.
- **טעות**: איפוס מיידי לתיבה 0 וחזרה בעוד שאלה אחת לחיזוק.
